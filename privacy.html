Privacy Policy

Effective date: November 20, 2026

Who uses this tool

Personal Drive Tool is a private utility used only by its owner, with the owner’s own Google account. It is not offered to the public.

Google Drive data accessed

  • Files in one folder of the owner’s Drive that the owner chooses, and its subfolders.
  • The tool reads files placed in that folder and writes its output files back to the same folder.
  • It does not access other files, contacts, email or any other personal data.

How data is used and shared

  • File contents are processed only to produce the owner’s requested output. Processing may use third-party services under the owner’s own accounts.
  • Files and results are stored only on the owner’s own server and in the owner’s Google Drive.
  • Data is not sold, not used for advertising and not shared with anyone else.

Google API data

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time on the Google Account permissions page.
